# sense — 仕様メモ (v0.1)

> 状態: 構想段階。訴求の軸はプロトタイプを触ってから決める。

## コンセプト

**量の感覚（色・長さ・面積・角度など）の「ちょっとした違い」で遊ぶゲームアプリ。**

> 表現ポリシー: 「脳トレ」「トレーニング」「訓練」は使わず、効果も謳わない (docs/monetization.md 参照)。

- 「今どこまで見分けられたか」をスコアとして楽しむ。効果の主張はしない
- あわせて、色見本・長さ・面積を**画面上に実寸で表示**できる (画面上の 5cm = 実際の 5cm)

## プラットフォーム

- **モバイルアプリ (iOS / Android)**
- 理由: 端末モデルから物理 PPI が取得でき、実寸表示がキャリブレーション不要で正確になる。
  Web のオンライン定規 (カード合わせで校正) に対する明確な優位点。
- フレームワークは未決 (候補: Flutter / KMP / ネイティブ)

## 機能

### メイン: 違いの識別あそび (「◯◯くらべ」)

対象は視覚の 4 感覚から開始: **色 / 長さ / 面積 / 角度**

拡張 (2026-08 決定): **聴覚・時間・数量** へ広げる
- 音の高さ (#6): どちらが高いか。セント差の階段法。倍音合成の擬似楽器音 (ピアノ風等) を混ぜ、音色が違っても高さで比べる
- 音名当て (#7): 絶対音感的クイズ (大人は準絶対音感として訴求)
- 時間感覚 (#8) / 数量感覚 (#9)
- コンセプトは「視覚・聴覚・時間の量感覚まるごと遊べる」に拡大

- 2 択比較 (どちらが長い・濃い等) や再現 (この角度を作れ・この色を作れ) の形式
- 正解に近づくほど差を小さくしていき、識別の閾値 (どこまで見分けられるか) を推定する
- スコアリング:
  - 色: CIEDE2000 (知覚的な色差)
  - 長さ / 面積 / 角度: 誤差 % (角度は度数でも可)
- 成長の可視化: 感覚ごとの閾値の推移、横断の総合スコア (例: センス偏差値)

### サブ: 実寸表示

- 色見本: **ズーム型**。タップすると色が広がり、全1,677万色 (2^24) に到達できる
  - 切り方は RGB 立方体の素直切り (案A): B軸スライス × R×G グリッド。各面がグラデーション状に見える
  - 基本形は各軸4分割 = 64タイル × 4段階 (64^4 = 2^24)。分割粒度は可変にできる設計
  - 色名 (JIS慣用色269 / 和色 / CSS148) はランドマークとして最寄り色名+色差を表示
  - 将来: OKLab (知覚均等) 切り、ピンチ連続ズーム
  - 表示色の限界 = 端末の色域/輝度は注記
- 長さ: 実寸の定規・任意の長さの表示
- 面積: 任意の面積 (例: A4、はがき、10cm²) を実寸表示
- あそびとの連携: 「くらべで当てる → 実寸で本物の 10cm を目に焼き付ける」の往復

## 競合状況 (2026-08 調査)

| 領域 | 状況 | 主な競合 |
|---|---|---|
| 色 | 激戦区 | I Love Hue (2,000万人)、Blendoku、X-Rite Hue Test、色違い探し、カラーIQ診断 |
| 角度 | 中程度・教育系中心 | Angle Master、Guess Angle、Angledle、NRICH |
| 長さ・面積の目測ゲーム | **ほぼ空白** | 計測アプリ (ARメジャー等) はあるが訓練アプリは実質なし |
| 実寸表示 | Web に多数 | ruler.im 等 (全て要キャリブレーション、±0.5mm 程度) |

**「色+長さ+面積+角度」を統合した感覚ゲームは見つからず。**

## 勝ち筋 (仮説)

1. 単能ゲームの上位コンセプト「量感覚まるごと遊べる」で統合。横断スコアはシェア動線にもなる
2. 実寸表示 × くらべあそびの往復は競合のどちら側にもない独自機能
3. 長さ・面積は競合空白 — 主役に据える選択肢もある
4. 色パズル市場 (癒し需要) が実証済み。色だけでは後発なので色単体では戦わない
